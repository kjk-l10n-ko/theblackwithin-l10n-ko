* 검수: 김작가
* 작업/번역: Claude Sonnet 5.5/Deepseek v4 flash

## 설정 방법

설정이 필요 없음. 설치 후 게임을 실행하면 바로 적용됨.

## 패치 내용

* 게임 UI·설정 화면·아이템 설명·스토리 문장 번역
* 한글 폰트 적용 (게임 원본 폰트에는 한글 글리프가 없음)
* 게임 폴더에 한국어 로컬라이제이션 pak과 폰트를 담은 `zz_KoreanPatch_P.pak` 하나를 추가함.
  기존 게임 파일은 변경하지 않음.
* 게임 시작 때 나오는 경고 화면(영상)은 번역하지 않아 영어 그대로 나옴.
