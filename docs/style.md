# 번역 스타일 — The Black Within

The Green Light 와 같은 개발사·같은 세계관(자매작)이라 말투와 표기는 `thegreenlight-l10n-ko/docs/style.md` 와 맞춘다.

## 톤

심리 공포물. 라일라의 독백이 중심이고, 초자연적인 존재가 속삭이듯 위협한다.
공포의 긴장을 살리되 과장하지 않는다. 아이템 설명은 차분한 백과사전 말투다.

## 화자별 말투

| 화자 | 말투 | 비고 |
|------|------|------|
| Laila (라일라) | 혼잣말·절망은 반말, Arne에게는 존댓말 | 초반 설렘 → 후반 공포. `Laila:` 접두 유지 |
| Arne (아르네) | 사무적 존댓말, 친절한 척 | 계약·규칙 설명은 계약서 말투 |
| Stranger (낯선 사람) | 위협적 반말 | `Stranger:` → `낯선 사람:` |
| Crow / 까마귀 | 대사 없음. 라일라가 까마귀를 `까마귀`로 지칭 | |
| 일기·메모 | 1인칭 평서체 `~다` | 줄바꿈(`\r\n`)과 문단 구조 그대로 |
| 아이템 설명 | 명사형 종결 | `A gas tank` → `가스통.` |

`이름:` 접두는 콜론+공백 형식을 그대로 두고 이름만 한국어로 바꾼다.
무대 지시는 괄호째 번역한다. 큰따옴표와 앞뒤 공백은 원문 그대로 둔다.

## 문체

- **UI 라벨·버튼**: 명사형, 짧게 (위젯 폭이 좁다). `Objectives` 목표, `Inventory` 인벤토리,
  `Resume Game` 게임 계속하기, `Quit Game` 게임 종료, `Load Game` 게임 불러오기.
- **설정 화면**: 명사형 (`Fullscreen` 전체 화면, `VSync` 수직 동기화, `FPS Limit` FPS 제한).
- **목표·안내**: `~하세요`체 (`Find the code for the safe.` → `금고 비밀번호를 찾으세요.`).
- **시스템 안내**: `~합니다`체 (`Game Saved` → `게임 저장됨`, `Diary updated.` → `일기가 갱신되었습니다.`).
- **아이템 설명**: 명사형 종결 + 마침표 유지.

## 조각 문자열 (중요)

일부 항목은 블루프린트에서 **아이템 이름 뒤에 이어 붙여** 표시된다
(`<이름>` + `" is empty."`, `"There is no "` + `<이름>`, `"added to "` + `"equipment."` 등).
`msgid` 자체가 조각이므로:

- 앞뒤 공백·마침표·`!` 를 **그대로** 둔다 (`"is empty."` → `"비어 있습니다."`).
- 서술어로 번역한다 (`"has been locked."` → `"잠겼습니다."`, `"added to equipment."` → `"장비에 추가했습니다."`).
- 조사는 붙이지 않는다. 아이템 이름 뒤에 조사 없이 이어지므로
  `"<열쇠> 잠겼습니다."` 처럼 읽히게 만든다. 어색하면 짧은 명사구로 끝낸다 (`"잠김."`).
- 조각을 문장으로 완성하지 않는다. 다른 조각과 합쳐질 수 있다.

## 형식 보존 (필수)

- `msgid` 의 **앞뒤 공백**을 그대로 유지한다 (예: `"instagram "`, `"Find the way out. "`).
- `\r\n`(실제 CRLF), `\n`, `<br>` 를 **바이트 그대로** 유지한다. 문단 수를 바꾸지 않는다.
- `{0}`~`{9}`, `%s`, `<태그>` 자리표시자는 위치·개수·순서를 바꾸지 않는다.
- URL(`http://`, `https://`, `steam://`)은 수정하지 않는다.
- 키 이름(`F`, `E`, `Tab`, `W`, `T`, `Space`, `Left Mouse`, `Shift`, `Ctrl`)은 번역하지 않는다.
  예: `Press E to Open` → `E 키를 눌러 여세요`, `[Tab]` → `[Tab]`.
- 숫자·비율·시간은 값은 그대로, 단위만 한국어로 (`100%`, `300 FPS`, `30`).
- `...` 는 원문 표기를 따른다(ASCII `...` / 유니코드 `…`). 말줄임표를 임의로 늘리지 않는다.
- 대문자 강조(`GAMEPLAY SETTINGS`)는 한국어에서도 강조로 살린다 (`게임플레이 설정`).

## 고유명사

- 인명: 라일라, 아르네, 프레드, 낯선 사람, 상사, 라파엘, 샤이엔.
- `The Black Within`(작품 제목)은 **검은 내면**. `The Green Light`(자매작)는 **초록빛**.
- `Cameroid` 카메로이드, `VHS` 그대로, `Mokoko` 모코코(브랜드), `Glowstick` 야광봉, `Torch` 횃불.
- 장소: 저택, 작은 오두막, 거실, 지하실, 다락, 마당.

## 번역하지 않는 항목

`locales/no_translate.txt` 참고 (URL·단독 숫자/기호·키 이름·브랜드 표기).
해당 `msgid` 는 `msgstr` 을 비워 두면 게임이 원문을 그대로 표시한다.
